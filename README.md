✍️ Basic Grammar Checker

Basic Grammar Checker is a simple web-based Text Analysis application that checks text for common grammar and writing mistakes and provides useful suggestions for improvement.

Live Application Link 
https://jananijoy15.github.io/Basic-Grammer-Checker/

✨ Features

- 📝 Enter or paste text
- 🔍 Detect basic grammar mistakes
- 🔠 Check sentence capitalization
- ❗ Check sentence-ending punctuation
- ␠ Detect unnecessary double spaces
- 📚 Detect common grammar mistakes
- 💡 Provide correction suggestions
- 📊 Display total issues found
- 📱 Mobile-friendly responsive interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the application in a web browser.
2. Enter or paste your text into the text area.
3. Click the Check Grammar button.
4. The application analyzes the text.
5. Detected issues and suggestions are displayed.

💡 Example

Input:

he go to college

Output:

Issues Found: 2

Suggestions:
• Start the sentence with a capital letter.
• Use "he goes" instead of "he go".
• Add punctuation at the end of the sentence.

📊 Grammar Checks

Check| Description
Capitalization| Checks whether the sentence starts with a capital letter
Punctuation| Checks sentence-ending punctuation
Double Spaces| Detects unnecessary spaces
Common Grammar| Detects selected common grammar mistakes
Suggestions| Provides basic corrections
